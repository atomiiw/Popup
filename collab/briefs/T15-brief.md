# T15 — commander → operator：各种回答格式在 popup 里的显示 + 拉宽（1.2.11-dev.14，用户批准 4 条消息）

先刷新并确认 `#jr-diagnostics` 的 version 是 `1.2.11-dev.14`。存 `collab/evidence/formats/t15/`。不改账号设置。只在「Popup 格式测试」对话里发，每条在不同的一段文字上开新 popup，等回答完全结束再发下一条。截图标准同 T2：只截 popup，完全不透明，PNG，打开后至少等 1.5 秒；长内容在 popup 内滚动分段截（-a、-b…）。

## 四条消息
1. `用一个回答同时展示：一个 6 列的对比表格、一段带很长一行的 Python 代码、一个任务清单（有勾选和未勾选）、一个行内公式和一个独立公式、一段引用。`
2. `用图表画出 2020–2025 年全球电动车销量的大致趋势。`（要 ChatGPT 自己的图表组件；如果它只给文字或代码，记下来即可，不要重发）
3. `搜索一下今天的主要科技新闻，列 3 条并附来源。`（要带来源标签 / 引用的回答）
4. `在地图上标出东京的三个著名景点。`（要地图或地点卡片；没有就记下）

## 每条看三种状态
- **A 刚生成**：回答结束后截 `n-fresh.png`，读 `.jr-popup-response` 的 innerText 存 `n-fresh.txt`。
- **B 拉宽**：拖 popup 的右边缘（或左边缘）把它拉到最宽（约 720px），截 `n-wide.png`。如果你的工具做不了拖拽，写明，跳过 B。
- **C 刷新后**：四条都做完后刷新一次（couldn't load 就从侧栏进），逐个打开截 `n-reload.png`，存 `n-reload.txt` 和 `.jr-popup-response` 的 outerHTML `n-reload.html`；如果能拖，再拉宽截 `n-reload-wide.png`。

## 每张都检查，逐项写通过 / 不通过
1. 没有原始标签或标记露出来（`<box`、`<icon`、`|---|`、``` ``` ```、`[x]` 这类）。公式在 C 里显示成 TeX 原文是**已知限制**，记下即可。
2. 没有东西超出 popup 边缘被截断：宽表格能横向滚动；长代码行能在代码块里横向滚动。
3. 拉宽后不变形：没有重叠、没有挤成一字一行、图表/卡片没有错位。
4. 图表（第 2 条）、来源标签（第 3 条）、地图（第 4 条）在 A 和 C 里各是什么样（C 里 Popup 自己画，可能只剩文字——如实描述，存 html）。
